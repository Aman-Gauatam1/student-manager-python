# Student Manager App (Python)

##  Description

Student Manager App is a simple command-line application built using Python. It allows users to add student records, view all students, and check whether a student has passed or failed based on their marks.

This project is designed for Python beginners to practice dictionaries, loops, conditional statements, and user input.

##  Features

* Add a new student
* View all student records
* Check student result (Pass/Fail)
* Menu-driven interface
* Simple and beginner-friendly code

##  Technologies Used

* Python 3

##  How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the following command:

```bash
python student_manager.py
```
